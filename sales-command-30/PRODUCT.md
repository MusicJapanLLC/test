# PRODUCT SPEC — 営業司令室 30

## 商品名
営業司令室 30

## 対象顧客
2〜20名程度のB2B企業。代表・営業責任者が営業を兼務し、Gmail / Google Calendar / Slack / スプレッドシートに情報が散っている会社。

## 解決する問題
- 商談後の追客漏れ
- 次アクション期限の失念
- 見込金額・商談予定・受注状況が散在
- 経営者が毎日複数ツールを巡回する負担

## 月額3万円に含む範囲
- Google Workspace 1組織
- Slack 1ワークスペース、営業チャンネル1つ
- 自動化フロー最大5本
- 営業KPIボード1つ
- 追客期限アラート
- 月1回30分の運用レビュー
- 軽微なルール変更 月1回
- 障害一次切り分け

## 初期費用
50,000円（税別）
含む: 30分ヒアリング / 接続設計 / OAuth設定補助 / Slack司令室 / KPI初期設計 / テスト運用

## 対応範囲外
- LinkedIn規約に反する自動DM、大量送信
- 顧客確認なしの自動メール返信
- 契約判断、価格判断、営業判断の完全自動化
- CRM全移行、大規模データクレンジング
- 独自基幹システム開発
- 24時間有人監視、即時復旧SLA
- API従量費、有料SaaS費用の立替

## 必要連携
必須: Gmail / Google Calendar / Slack
任意: Google Sheets / Make / 顧客既存CRM
OAuthは顧客本人のアカウントで実施し、共有パスワードを受け取らない。

## 導入フロー
1. 30分ヒアリング
2. 契約前チェック
3. 顧客側OAuth接続
4. 通知条件・KPI項目設定
5. テストデータで確認
6. 本番切替
7. 月次レビュー

## 管理画面
公開デモ: https://30-nnktft.v2.appdeploy.ai/
表示: パイプライン / 今月受注 / 商談予定 / 追客遅延 / 案件一覧 / 通知例 / 接続対象
デモ値は全て架空データ。

## ヒアリングフォーム
1. 営業担当人数
2. 月間商談数
3. Gmail / Calendar / Slack の利用有無
4. 現在の案件管理方法
5. 追客漏れが発生する場所
6. 1週間以上止まりやすい営業工程
7. 通知したい条件
8. KPIとして毎日見たい数字
9. 自動送信を許可する範囲（v1は原則なし）
10. 個人情報・機密情報の取り扱い要件

## 契約前チェック
- Google Workspace管理者の承認可否
- Slackアプリ導入可否
- 顧客が利用規約上許可されたAPIのみ使うこと
- 対象メール・カレンダー範囲の確定
- 個人情報・機密情報の分類
- 保存先と保持期間
- 障害時連絡先
- API/SaaS追加費用の負担者
- v1対応範囲の合意
- 解約時削除手順の合意

## データ方針
顧客情報を当社独自モデルの学習データとして二次利用しない。外部AIを使う場合は、対象データ、提供先、保持ポリシーを事前に明示し、必要最小限にする。
