## ケース SBW-02: 閲覧者入力からDOMへの注入

確認した `innerHTML` 代入は固定文字列である。パス比較は固定の分岐条件として使われ、外部script URLの可変部分はエンコードしたoriginである。この原文内では、クエリやfragmentなどの閲覧者入力がHTML文字列またはコードとして解釈される経路は確認できなかった。

判定: 確認した代入だけを根拠とするDOM XSSの仮説には反証がある。ただし、未取得の外部JS、バックエンド、他ページを含めたサイト全体の安全性を示す結論ではない。
