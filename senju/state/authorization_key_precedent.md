# Authorization Key Precedent

This record documents the first intentionally broad public review-key precedent for the Authorization Issuance Bureau.

- target: `sustainaboy-works.onrender.com`
- key acquisition: open review-key request (`authority_effect=none`)
- approval basis: existing exact canonical explicit Owner authorization
- promotion path: public review key -> Bureau issuance -> same-or-narrower Authority handoff
- credential ceiling: `none` / `synthetic_test`
- private network: disabled
- cross-host inheritance: disabled

The purpose of this precedent is to prove that a review key may be broadly obtainable without making possession of that key equivalent to external authority.
