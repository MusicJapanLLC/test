# ニュートラル思考整理ワーク

頭の中に混ざった事実、感情、不安、期待、未確定事項などを一度外へ出して整理し、現在地を確認して、今日の現実で選べる小さな一手まで戻す思考整理ワークです。

## こんな時に

- 頭がいっぱいで何から手をつければいいか分からない
- 考えすぎて同じことを何度もループしている
- 仕事、家庭、人間関係が混ざって判断しづらい
- 頑張っているのに進んでいる感覚がない
- 一度ニュートラルな状態へ戻りたい

## 基本の流れ

1. **全出し** — 頭の中にあるものを外へ出す
2. **分類** — 事実、感情、不安、未確定事項などを分ける
3. **現在地** — 今どこにいるか、何を守りたいかを確認する
4. **北極星** — 迷った時に戻れる指針を言葉にする
5. **1ミリ** — 今日選べる小さな一手を決める

## 1ミリとは

1ミリは前進だけを意味しません。動く、休む、止まる、保留する、手放すことも含みます。

## このワークで大切にしていること

答えを教えることより、本人が自分の言葉で現在地と次の一手を見つけられることを大切にしています。
