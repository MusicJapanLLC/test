# SUSTAINABOY WORKS

> 頭と心の大掃除。次の1ミリを、自分で選ぶ。

SUSTAINABOY WORKS（サスティナボーイワークス／SBW）は、頭の中に混ざった事実・感情・不安を外へ出して整理し、現在地を確認して、次の小さな一手を自分で選べる状態をつくる思考整理ブランドです。

## ニュートラル思考整理ワーク

特別な自己啓発ではなく、日常の延長で自分を整えるための少人数オンラインワークです。

### 基本の流れ

1. **全出し** — 頭の中のモヤモヤを外へ出す
2. **分類** — 事実、感情、不安、未確定事項などを分ける
3. **現在地** — 今どこにいるか、何を守りたいかを確認する
4. **北極星** — 迷った時に戻れる自分の指針を置く
5. **1ミリ** — 今日の現実で選べる最小の一手を決める

## こんな時に

- 何から手をつければいいか分からない
- 考えているのに頭の中が整理されない
- 仕事、家庭、人間関係が混ざって判断しづらい
- 頑張っているのに進んでいる感覚がない
- 一度ニュートラルに戻りたい

## 大切にしていること

答えを教えることより、本人が自分の言葉で現在地と次の一手を見つけられることを大切にしています。人生のハンドルをこちらが握らない、ファシリテーション型の整理です。
