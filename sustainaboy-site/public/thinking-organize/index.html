頭がごちゃごちゃしている時は、いきなり結論を出そうとしません。まず外へ出して、分けて、現在地を確認する。SUSTAINABOY WORKSでは、その順番を5つに整理しています。

SUSTAINABOY WORKS / 思考整理
頭の中を整理する最短の順番

①全部書き出す → ②種類ごとに分ける → ③今の現在地を一文で確認する → ④迷った時に戻る指針を決める → ⑤今日できる最小の一手に落とす、の順です。

「考える量」より「混ざっていること」が問題になる

仕事のタスク、相手への感情、将来への不安、まだ決めなくてよいことが、同じ場所で同時に回っていると、何から手をつけるか見えにくくなります。

SUSTAINABOY WORKSでは、頭の中を整理する時に「もっと正しく考えよう」とするより、まず混ざっているものを分けます。

頭の中を整理する5ステップ

1. 全出し

紙やメモに、今気になっていることを全部出します。タスクだけでなく、「嫌だ」「不安」「まだ決めたくない」といった感情や未確定事項も含めます。

2. 分類

仕事、人間関係、お金、家庭のようなテーマだけでなく、「事実」「感情」「予測」「今できること」「まだ決めなくていいこと」に分けるのも有効です。

3. 現在地

「今は何が確定しているか」「何を守りたいか」「どこまで決めれば十分か」を確認します。現在地が一文で言えるようになると、次に扱うものが絞りやすくなります。

4. 北極星

その場の正解を増やすのではなく、迷った時に戻れる指針を一つ置きます。「家族との時間を守る」「今月は体調を崩さない」のように、今の自分が戻れる言葉で十分です。

5. 1ミリ

最後に、今日の現実で選べる最小の一手へ落とします。休む、保留する、断る、手放す、も含みます。

具体例：仕事と人間関係が混ざっている時

たとえば「上司へ返事をしないといけない」「相手に嫌われた気がする」「転職したほうがいいかもしれない」が同時に浮かんでいるとします。

  1. まず3つとも紙へ出す
  2. 「返事が必要」は事実、「嫌われた」は推測、「転職」は大きな判断と分ける
  3. 現在地を「今日は返事だけ決めればよく、転職は今日決めなくていい」と置く
  4. 北極星を「仕事は丁寧に、人生の大きな判断は急がない」とする
  5. 1ミリを「17時までに返信文を作る」にする

全部を解決していません。それでも、今の現実で扱うものが見えます。

タスク整理と、思考整理は同じではない

タスク管理は「何をするか」を整理するのに強い方法です。一方で、迷いの中には、感情、未確定事項、守りたいもの、やらない選択も混ざっています。SUSTAINABOY WORKSの思考整理は、行動リストだけでなく、その前段階の「何を扱うか」を整理します。

いきなり答えを出さない。現在地が見えてから、次を選ぶ。

一人で整理しにくい時は、答えを決めない第三者を使う

同じところを何度も回ってしまう場合は、第三者が答えを教えるのではなく、話を分ける役に入る方法があります。SUSTAINABOY WORKSのニュートラル思考整理ワークは、この5ステップを対話と付箋で進めます。
