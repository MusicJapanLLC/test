# ギルドの灯 — 設計メモ

スマホ向けの「ギルド経営 × 放置」ゲームの試作。ボリュームは小さく、細部の作り込みと「やめどきが見つからない」流れを優先した。

---

## 1. 計画：どんなゲームか

**一言で**：ボロボロの冒険者ギルドを、住人が動き回る断面図の中で少しずつ大きくしていく。依頼の結果は「冒険譚」という縦スワイプのショート動画で届く。

### 中心の循環

```
依頼を受ける → パーティを派遣 → （待つ／放置）→ 冒険譚が届く
      ↑                                              ↓
  新しい依頼・職業・エリア ← 施設を建てる・強化 ← 報酬（ゴールド・素材・名声）
```

- 名声がたまるとギルドランクが上がり、施設・職業・エリアが解放される
- 序盤はわざと不便：冒険者1人、ベッド2台、同時派遣1件、酒場なし、チップは手で回収
- 発展するほど快適：派遣枠が増える、チップ自動回収（酒場Lv4）、相談料自動回収（ホールLv3）、受付嬢の自動派遣（ランク5）

### 画面

| 画面 | 内容 |
|---|---|
| ギルド（常に表示） | 断面図。冒険者・受付・バーテン・鍛冶師・錬金術師・客が自律的に動く。昼夜あり |
| 依頼 | 遠征中の進捗、掲示板、派遣するメンバー選び（成功率メーター） |
| 冒険者 | 仲間の一覧、求職者（雇う） |
| 冒険譚（中央） | ショート動画フィード。見ると報酬を受け取る |
| 施設 | 建設・強化。次に解放される階だけ見せる |
| 記録 | 統計、魔物図鑑、設定 |

## 2. 調査：何を見たか

Web 検索で、放置・経営ゲームのストアレビュー、ショート動画の依存性に関する記事と研究、Clash Royale などの継続設計の分析記事、ケルト音楽の構造を調べた。

**正直な件数**：個別に本文まで読めたユーザーレビューは約30件（Google Play / App Store / Reddit / 個人ブログ）。加えて、第三者サービスが Eatventure の最近のレビュー約120件を集計した分析を参照した。**指定の「300件以上」には届いていない**。もっと集めるなら、ストアのレビューを直接まとめて取得する方法を別途用意する必要がある。

### レビューから拾った不満（＝やらないこと）

| 不満 | 出典の例 | このゲームでの対策 |
|---|---|---|
| 広告が多すぎて遊べない | Idle Miner Tycoon のレビュー | 広告・課金なし |
| 落ちて数時間分の進行が消えた | Idle Mine! のレビュー | 5秒ごと＋タブを離れた瞬間に自動保存 |
| 「放置」のはずの旅が、放置中に進まない | Idle Guild のレビュー | 時間はすべて実時刻で管理。留守中も同じ計算で進む |
| ウィンドウが出るたびに時間が止まる・タップさせられる | カイロソフト作品のレビュー | お知らせは画面を止めないトーストにした |
| 同じ作業を1つずつやらされる | カイロソフト作品のレビュー | 「おまかせ」編成、まとめて受け取り、自動回収・自動派遣 |
| 眺めるだけの戦闘が長くて退屈 | プロレスリング物語のレビュー | 冒険譚は1本7秒前後。スワイプでいつでも飛ばせる（報酬は失わない） |
| 終盤に重くなる | きらめきスキー白書のレビュー | 描画を軽く保つ（測定で1フレーム約10ms／ソフト描画） |
| 留守番の上限が短すぎて離脱した | GDC講演（Egg, Inc. の2時間制限） | 留守番は基本3時間、見張り塔で最大13時間 |

### レビューから拾った「好き」（＝伸ばすこと）

- 冒険者が動くのを見守るだけで楽しく、気づくと時間が溶けている（冒険ダンジョン村のレビュー）
- 冒険者どうしの関係やランダムな出来事で、キャラクターに愛着がわく（Our Adventurer Guild の紹介記事）
- 収支を見ながら調整を繰り返すのが苦にならない、ほどよい忙しさ（冒険ダンジョン村のレビュー）
- 大きく稼げるようになり、新しい場所が開く瞬間が気持ちいい（Idle Miner Tycoon のレビュー）

## 3. 分析：中毒性の仕組みとシステムへの落とし込み

| 心理の仕組み | 参考にしたもの | このゲームでの形 |
|---|---|---|
| 変動比率強化（いつ当たるか分からない） | ショート動画のフィード、スロット | 依頼の結果は冒険譚を再生するまで分からない。成功／大成功／伝説級／撤退。いちばん良い結果は2〜3本目に置き直して期待を溜める |
| 手間のない連続視聴・自動再生 | TikTok / Shorts | 上スワイプで次へ、自動で次へ。最後のカードから「依頼を出す」で次の派遣に戻れる（輪が閉じる） |
| 小さな能動的な報酬 | いいね・ダブルタップ | ダブルタップで応援 → 冒険者の絆が深まり、戦力が少し上がる。戦闘中のタップで報酬+1%（最大10回） |
| 連続ボーナス | ログイン・コンボ系 | 冒険譚を続けて見るほどゴールド+5%ずつ（最大+30%） |
| 予約の仕組み（戻ってくる時刻を自分で決める） | Clash Royale の宝箱タイマー | 依頼ごとに所要時間が違う。15秒〜1時間。寝る前に長い依頼を出せる |
| ツァイガルニク効果（やりかけが気になる） | 目標リスト、進捗バー | 常に「次の目標」が1つ見えている（全31段）。名声バー、建設予定地の看板、施設タブの赤い点 |
| 情報は少しずつ見せる | 放置ゲームの設計記事（全部見えると謎が消える） | 施設は「次の1階」だけ見える。それより先は「？？？」。図鑑は見た魔物だけ埋まる |
| 不便→快適の成長実感 | 指定どおり | 序盤は手動回収・1枠派遣。強化で自動回収・自動派遣に変わる |
| ジュース（手触りの気持ちよさ） | ゲームフィールの記事 | コインが弧を描いてHUDへ飛び、取るたびに音程が上がる。ヒットで画面が揺れ、魔物はポリゴンの破片になって砕ける。振動も付けた |
| 社会的な反応 | コメント欄 | 冒険譚のコメント欄にギルドの仲間や受付のリナが書き込む |

**数値の設計**（模擬プレイで確認）：常に最適に遊ぶと、ランク2まで約5分、ランク3が約15分、ランク5が約1時間、ランク8が約5時間、ランク10が約13時間。実際は留守番の上限があるので、数日かけて伸びていく。

## 4. 作ったもの

- **グラフィック**：画像ファイルは使わず、すべて Canvas のベクター描画。面ごとに明暗を付けたローポリ調。端末の画素密度（最大2.5倍）で描くので細かい
- **音**：音声ファイルは使わず、Web Audio で合成。このゲームのために作曲したオリジナル曲が2つ
  - 「灯りの酒場」6/8 のジグ（ニ長調、AABB）— ギルドの曲
  - 「草原を行け」4/4 のリール（ホ・ドリア）— 冒険譚の曲
  - 楽器：ティンホイッスル（装飾音・後からかかるビブラート・息の音）、ハープ、フィドル、バウロン、ドローン。ループごとに編成が変わり、夜はテンポを落としてハープ中心になる
  - メニューを開くと音楽が少しこもる。タブを離れるとフェードアウトし、戻るとフェードイン。最後にリミッターを入れ、派手な効果音が重なっても割れない
- **昼夜**：実時間12分で1日。夜は窓と灯りが暖かく光り、煙突の煙、星、月が出る

### ファイル

```
guild/
  index.html        開発用（js/ と css/ を読む）
  css/style.css
  js/core.js        数学・乱数・色・書式
  js/data.js        職業・エリア・魔物・施設・ランク・目標・台詞
  js/audio.js       BGM と効果音
  js/art.js         人物・魔物・アイコンの描画
  js/sim.js         経済・依頼・留守番の計算・セーブ
  js/scene.js       ギルドの断面図と住人の動き
  js/reels.js       冒険譚（ショート動画）
  js/ui.js          HUD・メニュー・チュートリアル
  js/main.js        起動とループ
  build.mjs         1ファイルにまとめる（dist/ に出力）
```

### 動かし方

```
cd guild
python3 -m http.server 8000   # → http://localhost:8000
node build.mjs                # dist/index.html（単体で開ける1ファイル版）
```

## 5. デバッグで確かめたこと

ヘッドレス Chromium（390×844 のスマホ画面、360×640、1280×800）で次を確認した。

- チュートリアルの最初から最後まで（依頼 → 派遣 → 相談料 → 冒険譚 → 雇う）
- 冒険譚の各場面（登場・戦闘・とどめ・宝箱・結果）を大成功／撤退／伝説級で
- スワイプ、ダブルタップ、コメント欄、まとめて受け取り、最後のカード
- 留守番：2時間後に開くと、酒場の売上と帰還したパーティが「おかえりなさい」に出る
- 30倍速で施設建設・強化・派遣・冒険譚を繰り返す耐久テストでエラーなし
- 音量：BGM と効果音の大きさを測り、割れないことを確認

見つけて直した主な不具合：メニューが0.25秒ごとに描き直されて押せない、留守番の計算前にセーブが上書きされる、手に負えない依頼ばかりになると進行が止まる、1ファイル化で `$'` が置換文字列として解釈されて壊れる、ほか見た目の重なり多数。
