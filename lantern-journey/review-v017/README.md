## 範囲と実行方法
この PR はゲーム改修のレビュー用です。配信設定の追加・変更や自動公開は行いません。
画像・音声・フォントのバイナリ、サーバー、ビルド環境は本 PR に含めていません。
したがって、このディレクトリ単体は自己完結した開発環境ではありません。試遊は上記公開 URL を使用してください。
ゲーム全体の正本と素材は既存 Sites リポジトリの上記コミットにあります。
音声素材はゲームへの組み込み用途のためのものです。素材単独の再配布は禁止されています。
素材を独立した音声パックとして配布しないでください。出典は audio/CREDITS*.md を参照。
