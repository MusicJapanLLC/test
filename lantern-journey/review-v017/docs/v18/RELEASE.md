# 灯の旅路 v0.18 — 物語の仲間と、灯霊の加護

## 改修
- 物語ボイスを停止。戦闘・勝利の収録ボイスは保持
- 会話欄を画面下のコンパクトなパネルへ変更。文の長さでページ分割、日本語の語と助詞をまとめて折返し
- スプライトの切り抜き顔を専用イラストに変更。主要4人×3表情、住人3人×3表情、既存召喚20人×1、新灯霊6人×1 = 47セル
- 2Dドット戦闘を維持し、4人の配置と画像余白を調整
- 森の蝶・木の葉、海の反射、工房の火の粉、霧とゆっくりした背景移動
- 敵の詠唱・爪撃・魔弾・霜・護りなど行動別エフェクト。波開始時にステージ名、WAVE、敵数を表示し、表示中は進行待機
- 装備のレア度、装備者、装備中、能力、交換前後の戦力を表示
- アレンを優先する自動編成、加入済みの物語仲間で編成するボタン
- 既存召喚仲間を消費せず、物語4人の支援枠に装着可能。本人が出撃中は二重効果なし
- 成人女性の灯霊6体（6属性・6種族）。別召喚枠、均等1/6、全SSR、券1枚または無償石10。重複共鳴Lv.1–5、最大後は灯晶20
- 同じ保存キー・旧データ移行を維持。公式移行ボタンは非表示。配信設定の作業は再開していない

## 検証
- tests/v18-guardians.cjs: 旧データ移行、原子的な費用処理、不正抽選、重複成長、補償上限、支援枠・二重装着禁止、6属性の戦闘効果
- tests/v18-smoke.cjs: 新規開始→会話→初回戦闘→結果→無料10連→育成、実績受取、再読込、320×568 / 390×844 / 430×932
- tests/v18-review.cjs: 装備表示、灯霊10連、装着、セーブ再開、会話中に声が出ないこと、3サイズのボス会話・4人配置・開始表示。テスト用進行データ使用
- stage.js担当の独立Canvas確認: 45配置と85行動フレーム、reduced-motion。同じ座標計算で重なり・範囲外・例外を確認
- 実iPhone/Safari、全章全難度の長時間プレイ、聴感と演出の主観評価は未実施
- 実決済・計測は無効。新しい灯霊はローカル試作品であり、有償ガチャとしては公開していない

## 残る改善
- 既存召喚20人の追加表情は未制作（現在各1枚）
- SSRをすべて強制変換していない。既存編成の互換性を保ち、加護運用を選べる
- 灯霊の追撃頻度・成長費用と高難度の長期バランスは実プレイ評価が必要
- 新規章・新イベントの追加は今回の対象外

## 素材
新規差し絵はbuilt-in imagegenで生成。PNGからWebPへの圧縮のみ、5アトラス計約2.28MB。プロンプト・セル割当は同ディレクトリのJSON参照。Higgsfield/Figma/MagicPathで制作したという主張はしない
ギルドの灯の公開シーン実装を参考調査したが、コード・保存・素材は混ぜていない
