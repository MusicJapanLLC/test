# Lantern Journey v14 sound effects attribution

These sixteen v14 cues are original layered sound designs for Lantern Journey, using existing licensed local foley/sample derivatives and original procedural synthesis. Changes include selection and trimming, pitch/time resampling, envelopes, frequency filtering, stereo placement, soft saturation, gain, short room reflections, and original filtered-noise / damped-body synthesis. No metal-impact or metal-click recording is used in this pack. No new music was generated; owner-provided BGM is unchanged.

Kenney CC0 1.0 sources reused: `knifeSlice`, `knifeSlice2`, `chop`, `handleCoins2` from RPG Audio; `impactPunch_heavy_000`, `impactGeneric_light_000` from Impact Sounds; `ui-click1` from UI Audio. Existing project credits identify the original publication pages:

- https://kenney.nl/assets/rpg-audio
